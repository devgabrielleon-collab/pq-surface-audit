# Contributing

1. Abra uma issue descrevendo a melhoria.
2. Crie uma branch.
3. Faça mudanças pequenas e testáveis.
4. Rode `pytest -q`.
5. Abra um pull request claro e objetivo.

## Security-first
Este projeto é defensivo. Não envie contribuições que adicionem exploração de falhas, credential attacks ou enumeração agressiva.
